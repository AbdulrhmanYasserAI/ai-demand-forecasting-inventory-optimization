# Real dataset (optional)

For the full real-world run, download the **Walmart Store Sales Forecasting** dataset from the Kaggle competition:

https://www.kaggle.com/competitions/walmart-recruiting-store-sales-forecasting

Place `train.csv` in this folder.

The project expects these columns at minimum:

- `Store`
- `Dept`
- `Date`
- `Weekly_Sales`
- `IsHoliday`

The original competition data is not redistributed in this repository.

The default run uses the included deterministic synthetic retail-demand dataset so the repository works immediately after cloning.
